# Official sign assets

These 49 SVG files are unmodified FHWA Standard Highway Signs layouts. Only filenames were shortened for the local app. No sign graphic was generated by AI or redrawn in HTML, CSS or SVG.

The generated per-file provenance record is `app/data/fhwa-sign-provenance.json`. Each row identifies the FHWA phased release, archive file, exact archive entry, upstream SHA-256 and local SHA-256. `scripts/validate_app.py` verifies all 49 local files against that manifest without a runtime network request.

Sources:

- FHWA MUTCD 11th Edition, Standard Highway Signs phased releases: <https://mutcd.fhwa.dot.gov/kno-shs_2024-release-status/index.htm>
- Release 2, dated September 27, 2024: R3-7L and R16-3.
- Release 3, dated December 20, 2024: R1-1, R1-2, R2-1, R3-4, R4-1, R4-2, R4-3, R4-5, R5-1, R5-1a, R5-2, R7-1, R10-11, R12-1, R14-1, R14-3, R2-6aP, W3-4, W4-2R, W5-2, W7-1, W7-2bP, W8-4, W8-5, W8-6, W8-13, W8-14, W8-21 and G20-2.
- Release 4, dated March 12, 2025: R4-7, R6-1R, R12-2, W3-1, W4-1R, W6-2, W12-2, W20-1, W20-2, W20-4, W20-5L, W20-5R, W20-7a and W21-5bR.
- Release 6, dated February 10, 2026: D5-1, D8-1a, D9-16 and D9-17P.

The R2-1 source layout contains the legend `SPEED LIMIT 50`, so the app uses the same wording. The R16-3 source layout contains `MOVE OVER OR REDUCE SPEED`, so the app uses that exact wording. These files are not AI-generated and are not synthetic documents.

The remaining 31 entries are not presented as official sign graphics:

- 15 local, composite or variable-value messages use neutral training cards. Their form and numeric values can differ by State, facility or road operator.
- 16 changeable-message entries use a clearly labeled `TRAINING DMS` simulator. Message wording and line breaks can differ by operator.

FHWA states that the MUTCD is in the public domain and its online material may be used without separate permission. The app identifies FHWA and MUTCD as the source: <https://mutcd.fhwa.dot.gov/knowledge/faqs/faq_general.htm>
