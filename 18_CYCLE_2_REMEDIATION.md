# Truck Driver English: Cycle 2 remediation

Дата фактической сверки: 2026-08-21.

Этот документ описывает текущий код, сгенерированные данные и свежий интеграционный прогон Cycle 2. Он не переносит вперед неподтвержденные заявления из Batch 2, Batch 3, Batch 4 или Cycle 1.

Статусы в матрице:

- `Реализовано`: требуемый контракт присутствует в текущем runtime и имеет regression coverage.
- `Остаточное ограничение`: реализация проверена автоматически, но требуемая проверка, которую нельзя честно автоматизировать в этом цикле, явно названа в последнем столбце.

## Границы цикла

- Разрешенная область изменений: только `truck-driver-edition`.
- Исходный English Basic за пределами этой папки является read-only источником данных.
- Публикация, deploy и commit не выполняются.
- Платные API в Cycle 2 не вызываются. Аудио строится из локальных immutable seeds и локальной обработки.
- Реальный микрофон не включается. `getUserMedia` не вызывается в browser regression, permission не запрашивается, реальные записи не создаются. Проверка recorder выполняется только через safe mocks.
- Пользовательский origin `http://127.0.0.1:8002` не открывается и не очищается. Browser и localStorage проверяются на отдельном порту в изолированном профиле.
- Четыре целевых auditor YAML и четыре созданных текущим QA временных YAML удалены по точным путям. Более ранние browser artifacts сохранены.
- Символы U+2013 и U+2014 запрещены во всех текстовых файлах проекта.

## Готовностный вердикт

`NOT READY` для безусловного финального production signoff, потому что требуемое человеческое perceptual прослушивание clean, phone и roadside не было выполнено. Сохраняются четыре продуктовых ограничения: localStorage безопасно отклоняет state больше 2 MiB и при дальнейшем росте потребует IndexedDB; diagnostic не является CEFR или ACTFL assessment; ELP gate не является официальной roadside assessment; targeted WCAG checks не равны полной формальной accessibility certification. Acoustic profiles являются локальными учебными обработками, не field recordings.
