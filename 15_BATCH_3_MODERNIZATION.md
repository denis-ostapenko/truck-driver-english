# Batch 3 modernization

> SUPERSEDED HISTORICAL SNAPSHOT. This file records the Batch 3 milestone from 21 August 2026. It is not the current implementation contract. Use `17_CYCLE_1_REMEDIATION.md`, current data and current code.

## Historical scope

Batch 3 improved mobile layout, question self-assessment, ELP-only situations, profile visuals, paged sign cards, audio pauses and lesson disclosure. Its self-assessment still did not provide the final spaced mastery model, and its sign and cache statements are obsolete.

The bank of 75 questions and commands is now named representative training prompts. These prompts are not an official standardized script.

## Superseding Cycle 1 changes

1. ELP Step 1 is a fixed five-item gate. A result of prompted or failed does not pass. Step 2 is unavailable until all five are independent.
2. Mastery requires two independent unsupported retrievals separated by at least 24 hours. Revealing a model cannot create mastery.
3. Step 2 includes 49 official FHWA SVG and 16 `TRAINING DMS`. The separate 15 variable-local cards are training content.
4. Diagnostic now has 12 tasks, three per construct, randomized answer positions and productive rubric-based items. It is not a validated CEFR or ACTFL assessment.
5. Semantic IDs and a 640-entry migration map replace positional content IDs. State schema 3 deeply normalizes imported nested records.
6. Typed slots separate display and spoken forms for time, weight, duration and identifiers.
7. Tractor-trailer, Hotshot open and Hotshot enclosed are filtered through explicit applicability metadata.
8. Listening uses a complete 75-row matrix with distinct clean, phone and roadside local files. The UI states that they are training processing profiles, not field recordings.
9. Current service worker cache names are versioned by code. Old Batch 3 version numbers are historical only.

## Historical evidence status

The Batch 3 desktop, mobile, offline and audio checks are retained only as a record of that milestone. They are not current regression evidence. Current checks are listed in `17_CYCLE_1_REMEDIATION.md`.
