## ELD Data Transfer Instruction Sheet

This training sample uses a telematics ELD. A telematics ELD supports both Web Services and Email. A local-transfer ELD instead supports both USB 2.0 and Bluetooth. Use only the methods supported by the specific registered device.

1. Open `Roadside Inspection`.
2. Select `Data Transfer`.
3. Ask the safety official which supported method to use.
4. Select `Web Services` or `Email` as directed.
5. Enter the output file comment exactly as provided by the safety official.
6. Review the date range: current day plus previous seven consecutive days.
7. Select `Send` once.
8. Report the displayed transfer result.

Practice phrase: `Which supported transfer method would you like me to use?`

Primary source: https://www.fmcsa.dot.gov/hours-service/elds/eld-data-transfer-faqs
