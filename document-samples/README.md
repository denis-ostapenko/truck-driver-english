# Training Document Pack

Every file in this directory is a synthetic language-training mockup.

`TRAINING SAMPLE, NOT VALID` means:

- it is not a government, carrier, insurance or shipping document;
- every identity and identifier is invented;
- it may not be presented during a real trip or inspection;
- the layout teaches field recognition and spoken answers only.
